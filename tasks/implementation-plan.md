# Plan de Implementación – HappyBee

1. **Hito 1:** Definición SDD (`requirements.md`, `specs/`, `docs/`, `tasks/`) y línea gráfica.
2. **Hito 2:** Configuración Flutter + Firebase Auth (registro, login, logout).
3. **Hito 3:** CRUD de perfiles infantiles y reglas de seguridad en Cloud Firestore.
4. **Hito 4:** Temporizador de cepillado de 2 minutos y captura con cámara real.
5. **Hito 5:** Panel parental, historial y ejecución de pruebas en dispositivo físico.
6. **Hito 6:** Firma digital, compilación de APK release y AAB, y publicación en GitHub Releases.
