# Arquitectura del Sistema – HappyBee

- **Frontend Móvil:** Flutter (Dart) ejecutado en Android (dispositivo físico Samsung Galaxy A15, Android 15).
- **Backend Serverless:** Firebase Authentication (identidad) y Cloud Firestore (persistencia NoSQL en tiempo real).
- **Patrón:** Separación por pantallas (`screens/`), servicios (`services/`) y modelos de datos (`models/`).
