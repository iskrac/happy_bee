# Manual de Identidad Visual – HappyBee

- **Paleta HEX:** Amarillo Miel `#FFC107`, Ámbar `#FFA000`, Azul Confianza `#1E88E5`, Blanco `#FFFFFF`, Texto `#212121`.
- **Tipografía:** Sans-serif redondeada de alta legibilidad para público infantil (7–12 años).
- **Estilo Gráfico:** Mascota abeja amigable con íconos claros y alto contraste.
